# EM 期刊账号登记（子目录）

记录「本人的投稿系统里，哪些期刊已经有账号」。

**本页只登记账号归属，不保存任何密码或设密链接。**

## 线上只显示 6 个字段

| 字段 | 说明 |
|---|---|
| journal | 期刊名 |
| publisher | 出版社 / 投稿系统 |
| username | 注册时用的用户名（3 本直接用邮箱当用户名） |
| email | 收到注册通知或投稿邮件的邮箱 |
| registered_at | 注册邮件日期（无注册信者为 —） |
| status | 有账号 / 有账号（据投稿记录） |

**本目录内的任何文件都不含、也不允许含：登录链接、一次性设密链接、重置链接、密码。**
需要这些信息时，只在本人电脑的私有目录 `hermes_work\em-accounts-local\` 内查看，该目录不在本仓库、不进 git、不上 Pages。
